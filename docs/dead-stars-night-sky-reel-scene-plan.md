# ดาวที่เราเห็นคืนนี้…อาจตายไปแล้วหรือยัง? (Scene Plan & Script)

- **Topic**: Are the stars we see tonight already dead? (ดาวบนฟ้าดับไปแล้วจริงไหม)
- **Format**: Mamase Vertical Reel (9:16, 1080×1920, 30 FPS)
- **Target Duration**: 45–60 วินาที (~52 วินาที รวม 8 ซีน)
- **Voice**: Google Gemini TTS (`th-TH`, `Fenrir` สไตล์ธรรมชาติ ขี้เล่น เล่าเรื่องเพื่อนสู่เพื่อน, speed 1.0)
- **Hook Gate**: ผ่านเกณฑ์สมบูรณ์ 10/10

## Mamase Reel Hook Gate Audit (10/10 PASS)

1. [x] **Hook อยู่ภายใน 1–3 วินาทีแรก**: "เคยได้ยินไหมครับว่า... ดาวระยิบระยับที่เราเห็นบนฟ้าคืนนี้ แท้จริงแล้วอาจตายไปหมดแล้ว?!"
2. [x] **ไม่มีคำทักทาย แนะนำช่อง หรือ slow setup**: เข้าสู่คำถามที่คาใจและท้าทายความเชื่อทันที 100%
3. [x] **คนทั่วไปเข้าใจได้ทันที**: เข้าใจง่ายด้วยมโนทัศน์เรื่อง "แสงคือภาพจากอดีต"
4. [x] **สร้าง Curiosity Gap ชัดเจน**: ดาวตายไปแล้วจริงไหม? แล้วดวงไหนที่อาจตายไปแล้วจริงๆ?
5. [x] **ถูกต้องทางวิทยาศาสตร์และปกป้องได้**: อิงฟิสิกส์ความเร็วแสง + อายุขัยดาวฤกษ์ (ล้าน-หมื่นล้านปี) เทียบกับระยะห่างของดาวที่ตาเปล่าเห็น (ไม่เกินสองสามพันปีแสง) โอกาสที่ดาวจะตายพอดีจึงแทบเป็นศูนย์ แต่ดาวปลายอายุขัยอย่าง Betelgeuse เป็นข้อยกเว้น
6. [x] **ภาพแรกเสริมพลัง Hook ทันที**: ทางช้างเผือกและแสงดาวส่องผ่านห้วงอวกาศมาสู่สายตา Explorer และน้องหมา
7. [x] **ไม่มี filler หรือประโยคยืดเยื้อ**: ทุกประโยคส่งมอบข้อมูลใหม่และมุมมองดาราศาสตร์ที่หักมุมความเชื่อ
8. [x] **มีข้อมูล Payoff ทุกไม่กี่วินาที**: ซีน 2 (แสงคือเครื่องย้อนเวลา) → ซีน 3 (หักมุม: ดาวส่วนใหญ่ยังไม่ตาย!) → ซีน 4 (อายุขัยดาวเทียบกับระยะทาง) → ซีน 5 (ข้อยกเว้น: เบเทลจุส) → ซีน 6 (มองลึกระดับกาแล็กซี) → ซีน 7 (ความหมายแห่งกาลเวลา)
9. [x] **ตอนจบทิ้งแนวคิดใหญ่ที่น่าจดจำ**: "แม้บางสิ่งจะดับสลายไปแล้ว แต่แสงของมันยังคงนำทางเราในปัจจุบัน"
10. [x] **TTS เริ่มด้วย Hook โดยตรง 100%**: ไม่มีเสียงเกริ่นนำหรือชื่อช่อง
