# Wan2.2 TI2V on RunPod A40 — Rebuild & Handover Guide

Last verified: 2026-08-31

## 1. Goal

Run **Wan2.2 TI2V 5B** on a RunPod GPU Pod for image-to-video generation using **native ComfyUI nodes only**.

This setup was verified to work successfully on an **NVIDIA A40 48 GB** Pod.

The current design target is:

- Still image → Wan2.2 motion video
- Thai speech is **not** generated by this Wan endpoint
- Future full pipeline: **Wan2.2 → Thai TTS → Lip-sync → FFmpeg**

## 8. API Runner Compatibility Fix

Runner:

```text
/workspace/wan22-ti2v.py
```

ComfyUI's current `SaveVideo` API response exposed the MP4 under the generic:

```text
images
```

output field.

The runner originally checked only:

```text
videos
gifs
```

Compatibility fix:

```python
files += (
    out.get("videos", [])
    + out.get("gifs", [])
    + out.get("images", [])
)
```

This allowed the runner to correctly detect the MP4 produced by `SaveVideo`.

## 14. Before Deleting the Current Pod

Because there is **no persistent volume**, back up the small reusable configuration/scripts and any outputs you want to keep.

Create one archive inside `/workspace`:

```bash
cd /workspace

tar -czf wan22-runpod-backup.tgz \
  start-comfyui.sh \
  wan22-ti2v-workflow.json \
  wan22-ti2v-api.json \
  wan22-ti2v.py \
  WAN22-INSTALL.log \
  light-year.png \
  ComfyUI/output/video/wan22-ti2v_00001_.mp4 \
  ComfyUI/output/video/wan22-ti2v_00002_.mp4
```

Verify:

```bash
ls -lh /workspace/wan22-runpod-backup.tgz
```

Then download:

```text
/workspace/wan22-runpod-backup.tgz
```

through the RunPod Jupyter file browser before terminating the Pod.

There is no need to back up the ~17 GiB model files if recreating them from the official Hugging Face repository is acceptable.

## 15. Rebuild Strategy for a Fresh Pod

For a new temporary Pod:

```text
1. Create RunPod A40 48 GB Pod
2. Enable SSH + Jupyter
3. Verify nvidia-smi / PyTorch CUDA
4. Clone ComfyUI
5. Create Python venv with system site packages
6. Install ComfyUI requirements
7. Download the three Wan2.2 model files
8. Restore wan22-ti2v.py and workflow JSON files
9. Restore/fix start-comfyui.sh
10. Start ComfyUI on 0.0.0.0:8188
11. Check /system_stats
12. Upload input image
13. Run wan22-ti2v.py
14. Download generated MP4
15. Delete Pod when finished
```

This avoids paying stopped persistent-volume storage cost.
